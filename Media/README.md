# 📸 High-Resolution CAD Renders, Match Media & Action Clips

This directory serves as the visual gallery for our National Champion RoboCup autonomous soccer robot. It hosts high-resolution CAD renders, physical hardware photos, exploded assembly diagrams, and match performance videos.

---

## 📂 Visual Assets Catalog

When browsing or adding media to this directory, files are categorized as follows:

- `/Renders` — High-definition CAD renders (Fusion 360 / Keyshot) showcasing assembly details, chassis tiers, and component integration.
- `/Photos` — High-resolution photography of the assembled physical robot, custom PCBs, and 3D printed mechanical modules.
- `/Videos_GIFs` — Short match highlights, omniwheel kinematics demonstrations, active dribbler testing, and field positioning clips.
- `/Exploded_Views` — Technical isometric exploded diagrams showcasing screw placements and layered mechanical assembly.
